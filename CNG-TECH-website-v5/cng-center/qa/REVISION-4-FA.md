# نسخه چهارم — اصلاح فرم مطابق درخواست مالک سایت

- منوی انتخاب سن با تیک کوچک «مالک زیر ۱۸ سال است» در ابتدای فرم جایگزین شد؛ پیش‌فرض بدون تیک است.
- بدون تیک: کد ملی مالک، تاریخ تولد مالک، شماره همراه به نام مالک و پلاک خودرو فعال‌اند.
- با تیک: شماره همراه مالک دیده می‌شود اما غیرفعال است؛ بخش مشخصات پدر یا مادر شامل نسبت، کد ملی، تاریخ تولد و شماره همراه به نام همان والد نمایش داده می‌شود.
- با برداشتن تیک، بخش والد پنهان و غیرفعال و شماره مالک دوباره فعال می‌شود.
- کد ملی، تاریخ تولد مالک و پلاک در هر دو حالت باقی می‌مانند. فقط شماره همراه مرتبط با حالت انتخاب‌شده ارسال می‌شود؛ مقادیر فیلدهای غیرفعال ارسال نمی‌شوند.
- قرارداد API و پنل مدیریت تغییر نکرده‌اند: `mobile` برای بزرگسال شماره مالک و برای زیر ۱۸ سال شماره والد انتخاب‌شده است. مالکیت سیم‌کارت در این سایت استعلام نمی‌شود.

## آزمون‌های این نسخه

- ساخت پیش‌نمایش و بررسی ساختاری: ۱۴ صفحه، ۳۰۵ ارجاع محلی، ۱۴ بلوک JSON-LD؛ موفق.
- آزمون‌های Node.js: ۸ آزمون موفق.
- آزمون واحد PHP: ۳۳ assertion موفق.
- آزمون مرورگر اختصاصی فرم: ۵۸ بررسی موفق در Chromium، عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰؛ بدون خطای JavaScript.
- شامل تیک با صفحه‌کلید، نمایش/عدم نمایش مشخصات والد، غیرفعال‌شدن شماره مالک، اجباری‌بودن شماره والد، بازگشت به حالت بزرگسال، انتخاب شماره صحیح هنگام ارسال، عدم ارسال داده غیرفعال، خطای ارسال و بازیابی شماره پیگیری است.
- گزارش: `qa/form-v4-browser-report.json`. تصاویر جدید با نام `form-v4-*.png` در پوشه screenshots قرار دارند.
- این آزمون مرورگر از پاسخ شبیه‌سازی‌شده API و داده ساختگی استفاده کرده است؛ آزمون یکپارچه PHP/MySQL و cPanel در این نسخه تکرار نشده‌اند. گزارش نسخه سوم و گزارش‌های قبلی، سوابق تاریخی هستند.

برای تکرار آزمون مرورگر پس از ساخت، Playwright Core و Chromium متناظر لازم است:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright-core node scripts/browser-request-form.cjs
```

## نصب

سایت هنوز آنلاین نشده است. بسته شامل خروجی پیش‌نمایش noindex است؛ فرم واقعی به HTTPS، PHP/MySQL و تنظیمات خصوصی نیاز دارد. راهنماهای `docs/DEPLOY-FA.md` و `docs/REQUESTS-SETUP-FA.md` را دنبال کنید. برای انتشار عمومی ابتدا خروجی production بسازید و آزمون‌های هاست را با داده ساختگی انجام دهید.
