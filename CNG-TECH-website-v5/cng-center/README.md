# CNG TECH — راهنمای پروژه

وب‌سایت فارسی، راست‌به‌چپ و واکنش‌گرا برای خدمات CNG، تنظیم موتور و مکانیکی در گنبد کاووس.

## شروع سریع

نیازمند **Node.js نسخه ۲۰ یا جدیدتر** فقط روی رایانه توسعه‌دهنده؛ نصب بسته یا `npm install` لازم نیست.
از داخل پوشه پروژه اجرا کنید:

```sh
node scripts/build.mjs
node scripts/check.mjs
node --test
node scripts/serve.mjs
```

سپس `http://127.0.0.1:4173` را باز کنید. با `Ctrl+C` سرور متوقف می‌شود. باز کردن مستقیم HTML با `file://` مناسب نیست، چون مسیر دارایی‌ها از ریشه سایت و ابزارها ماژولی هستند.

**پوشه `dist/` همراه این بسته در حالت پیش‌نمایش است: `noindex` و منع خزش.** برای انتشار عمومی، پس از تأیید اطلاعات، مطابق `docs/DEPLOY-FA.md` خروجی production بسازید. این نسخه هنوز روی دامنه نصب نشده است.

گزارش نهایی و آزمون‌های نسخه پنجم: `qa/REVISION-5-FA.md`.
گزارش تاریخی اصلاح فرم نسخه چهارم: `qa/REVISION-4-FA.md`.
گزارش تاریخی نسخه سوم: `qa/FINAL-REPORT-FA.md`.

## امکانات

- صفحه اصلی، خدمات، راهنمای طرح تبدیل، محاسبه هزینه سوخت، مجله، تماس و حریم خصوصی.
- شش مقاله مستقل، جست‌وجو و فیلتر دسته‌بندی.
- محاسبه‌گر محلی با اعداد فارسی/عربی/لاتین و نرخ ورودی کاربر؛ بدون جمع‌آوری اطلاعات شخصی.
- بررسی اولیه سال مدل با پیام مشروط؛ نه تأیید پذیرش یا ثبت‌نام طرح.
- تماس مستقیم و مسیریابی نشان؛ واتساپ و شبکه اجتماعی تأییدنشده نمایش داده نمی‌شوند.
- عنوان و توضیح اختصاصی، canonical، Open Graph، نقشه سایت و داده ساختاریافته.
- فونت محلی Vazirmatn، تصاویر سبک WebP، منوی موبایل و صفحه 404.

این پروژه اکنون فرم درخواست پیگیری و پنل خصوصی درخواست‌ها با PHP/MySQL دارد؛ این بخش بدون تنظیمات خصوصی و HTTPS غیرفعال است. پنل فقط برای مشاهده، تغییر وضعیت و حذف درخواست‌هاست و مدیریت محتوای صفحات نیست. ثبت‌نام رسمی، پرداخت و نوبت‌دهی آنلاین انجام نمی‌شود. تغییر محتوای سایت از فایل‌ها و ساخت مجدد انجام می‌شود. امکانات سئو تضمین رتبه گوگل یا نمایش نتایج ویژه نیستند.

**برای راه‌اندازی فرم حتماً `docs/REQUESTS-SETUP-FA.md` را بخوانید.** پیش‌نمایش امن با `node scripts/serve.mjs` است؛ Live Server یا میزبان استاتیک نباید فایل‌های PHP را عمومی سرو کنند.

## ساختار فایل‌ها

| مسیر | کاربرد |
| --- | --- |
| `public/api/` و `public/admin/` | API دریافت درخواست و پنل خصوصی PHP |
| `scripts/request-section.mjs` | فرم صفحه اصلی؛ بدون دریافت کد ورود |
| `deploy/schema.sql` | ساخت جداول درخواست‌های رمزگذاری‌شده |
| `config/site.json` | مشخصات مرکز، دامنه، ساعت کار، لینک‌ها و مبنای راهنمای طرح |
| `content/articles.json` | متن شش مقاله، منابع، تاریخ و مطالب مرتبط |
| `scripts/pages.mjs` | محتوای صفحات ثابت و بخش‌های صفحه اصلی |
| `scripts/shared.mjs` | قالب مشترک، منو، فوتر و داده ساختاریافته |
| `scripts/build.mjs` | ساخت HTML و فایل‌های سئو |
| `public/assets/` | CSS، جاوااسکریپت، فونت و تصاویر |
| `design/` | منابع SVG تصاویر مفهومی و طرح کارت اشتراک‌گذاری |
| `dist/` | خروجی نهایی قابل میزبانی؛ مستقیماً ویرایش نشود |
| `tests/` | آزمون منطق ابزارها و سرور محلی |
| `qa/` | گزارش آزمون مرورگر و تصاویر پیش‌نمایش |
| `docs/` | راهنماهای انتشار، ویرایش و تصاویر |
| `deploy/` | نمونه تنظیمات Apache و Nginx |

## قبل از انتشار

۱. دامنه و هاست را فعال و SSL را نصب کنید.
۲. نشانی دقیق، اطلاعات تماس و ساعات کار را بررسی کنید.
۳. عکس‌های واقعی مجاز را جایگزین کنید یا برچسب تصاویر جایگزین را نگه دارید.
۴. وضعیت روز طرح را از سامانه رسمی بررسی کنید؛ پذیرش مرکز و مجوزهای تخصصی در این نسخه تأیید نشده‌اند.
۵. خروجی production را بسازید و فقط محتوای `dist/` را روی ریشه دامنه قرار دهید.

راهنمای کامل: `docs/DEPLOY-FA.md`، `docs/EDITING-FA.md`، `docs/IMAGES-FA.md`.

## حقوق دارایی‌ها

- فونت Vazirmatn با مجوز SIL Open Font License؛ متن مجوز در `public/assets/fonts/OFL.txt` حفظ شود.
- تصویرسازی‌ها و آیکون‌های SVG همراه پروژه، طرح‌های مفهومی این وب‌سایت هستند؛ عکس واقعی مرکز نیستند.
- برای عکس‌های جایگزین واقعی، اجازه صاحب اثر و اشخاص قابل‌شناسایی لازم است.
- مجوز نرم‌افزار متن‌باز عمومی برای کل پروژه اعلام نشده است (`UNLICENSED` در package.json).
