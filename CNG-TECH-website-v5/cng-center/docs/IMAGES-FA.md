# راهنمای تعویض تصاویر

تمام تصاویر فعلی، تصویرسازی مفهومی‌اند و **عکس واقعی CNG TECH نیستند**. برچسب جایگزین و توضیح alt عمداً نمایش داده می‌شود.

## تصاویر پیشنهادی از مجموعه

| فایل | عکس پیشنهادی |
| --- | --- |
| `public/assets/images/cng-service.webp` | بررسی سامانه CNG توسط نیروی متخصص |
| `public/assets/images/diagnostics.webp` | دستگاه عیب‌یابی یا تنظیم موتور در محیط واقعی |
| `public/assets/images/mechanic.webp` | بخش مکانیکی و ابزار واقعی مجموعه |
| `public/assets/images/team.webp` | تیم مرکز با رضایت اشخاص حاضر در عکس |
| `public/assets/images/workshop.webp` | نمای واقعی مجموعه یا فضای تعمیرگاه |

ابعاد پیشنهادی ۱۲۰۰×۹۰۰ پیکسل با نسبت ۴:۳، فرمت WebP و حجم حدود ۱۰۰ تا ۲۵۰ کیلوبایت. سوژه اصلی از لبه‌ها فاصله داشته باشد، چون در برخی چیدمان‌ها برش می‌خورد. عکس فضای کاری ایمن و حرفه‌ای باشد؛ چهره بدون رضایت، پلاک و اطلاعات شخصی مشتریان را پوشانده یا حذف کنید.

## تعویض از طریق تنظیمات

۱. عکس واقعی مجاز را داخل `public/assets/images/` قرار دهید. می‌توانید نام موجود را حفظ یا نام جدید انتخاب کنید.
۲. در شیء `site` داخل `config/site.json` کلید اختیاری `images` اضافه کنید. برای مثال:

```json
"images": {
  "diagnostics": {
    "src": "/assets/images/diagnostics-real.webp",
    "alt": "دستگاه عیب‌یابی خودرو در مرکز سی‌ان‌جی تک گنبد کاووس",
    "placeholder": false
  }
}
```

۳. به همین روش برای کلیدهای `cng-service`، `mechanic`، `team` و `workshop` تنظیم بنویسید. فقط پس از جایگزینی واقعی، `placeholder` را `false` کنید. کلیدهای حذف‌شده همچنان با تصویر مفهومی و برچسب جایگزین نمایش داده می‌شوند.
۴. build و check را دوباره اجرا کنید و تصویر را در موبایل و دسکتاپ ببینید.

وجود `placeholder: false` فقط برچسب و متن جایگزین را تغییر می‌دهد؛ واقعی بودن عکس را راستی‌آزمایی نمی‌کند. مسئولیت تأیید با مدیر محتواست.

## تصویر بزرگ بالای صفحه اصلی

تصویر خودرو در `public/assets/hero.svg` یک تصویرسازی مستقل است، نه یکی از عکس‌های قابل تنظیم بالا. حفظ آن به‌عنوان طرح گرافیکی برند اشکالی ندارد. برای جایگزینی با عکس واقعی، مسیر img، ابعاد، متن alt و برچسب `hero-placeholder` در تابع `home()` فایل `scripts/pages.mjs` باید هماهنگ تغییر کنند. در صورت تغییر نسبت تصویر، CSS بخش hero را نیز بررسی کنید.

## کارت اشتراک‌گذاری و لوگو

- کارت فعلی: `public/assets/social-card.png` با ابعاد ۱۲۰۰×۶۳۰.
- منبع قابل ویرایش: `design/social-card.html`. برای خروجی PNG باید با مرورگر و ابزار تصویربرداری مناسب رندر شود؛ build معمولی این تصویر را دوباره تولید نمی‌کند.
- favicon: `public/assets/favicon.svg`.
- تصویرسازی‌های اصلی: `design/*.svg`. فرمان `node scripts/artwork.mjs` منابع SVG مفهومی را می‌سازد، نه تصاویر WebP؛ تبدیل SVG به WebP نیازمند ابزار تبدیل تصویر است. برای استفاده معمول سایت لازم نیست این فرمان را اجرا کنید.

پس از جایگزینی همه عکس‌ها، متن توضیح تصاویر در صفحه حریم خصوصی (`privacy()` در `scripts/pages.mjs`) را مطابق واقع اصلاح کنید. اگر هنوز تصویرسازی یا جایگزین باقی مانده، توضیح شفاف آن حفظ شود.
